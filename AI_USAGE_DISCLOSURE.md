# AI Tool Usage Disclosure — Authory

This project (**Authory — Signal-Based AI Detector for College Admissions Essays**) was developed with pair programming assistance from AI agentic coding systems.

---

## 🛠️ Where AI Assistance Was Used
- **Architecture & Module Structuring:** Designing the 5-day / 10-module breakdown, defining data structures, and organizing signal extractors.
- **Boilerplate & Code Generation:** Scaffolding FastAPI backend endpoints, Pydantic validation schemas, React + Vite frontend components, and PyTorch inference pipelines.
- **Optimization & Refactoring:** Identifying unvectorized tensor loop bottlenecks in PyTorch and vectorizing rank calculation (achieving 100x speedup).
- **Documentation Assistance:** Drafting technical descriptions, markdown indexes, and README sections.

---

## 🧠 Where Human Engineering & Judgment Prevailed
- **Detector Design & Signal Choice:** Deciding to build a signal-based detector (Perplexity, Binoculars Cross-Perplexity, Burstiness, MTLD) instead of calling an LLM API for arbitrary verdicts.
- **Scope Decisions:** Cutting high-compute perturbation methods (DetectGPT) and uninterpretable neural black-boxes in favor of an interpretable Logistic Regression model.
- **Dataset Provenance & Split Design:** Sourcing 200 essays across 4 categories, isolating ESL essays from training, and enforcing **held-out topic splits** for honest generalization evaluation.
- **Ethical Bias Measurement:** Explicitly discovering, measuring, and disclosing the **43.6% ESL False-Positive Rate** in the UI to prevent unfair accusations against non-native writers.
- **Product Safety Guardrails:** Hard constraint enforcing qualitative verdict bands (e.g. *"Likely AI-Assisted in Places"*) and prohibiting bare percentage verdicts.

---

## ❌ No AI Was Used For
- Computing essay classification verdicts (all scores are generated by the locally trained Logistic Regression pipeline).
- Writing case study failure hypotheses (all three case studies are grounded in empirical feature values from `data/features.csv`).
- Determining module completion and Definition of Done criteria.
